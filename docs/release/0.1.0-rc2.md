# FastPauli 0.1.0-rc2 Release Evidence

Status: published as GitHub prerelease `v0.1.0rc2` with source distribution,
macOS arm64 CPU wheel, and external checksum manifest artifacts.

## Scope

`0.1.0-rc2` is the second CPU-focused release-candidate lane for FastPauli. It
promotes the post-`0.1.0rc1` release-readiness hardening into a public
checkpoint without changing runtime APIs, accelerator packaging, or package
index publication status.

The release artifact support boundary is:

```text
CPU source distribution
CPU wheels for platforms that pass build, install, import, and scalar fallback evidence
CUDA source builds remain available when explicitly enabled from source
ROCm/HIP source builds remain available when explicitly enabled from source
Apple Metal source builds remain available when explicitly enabled from source
CUDA wheels remain unavailable
ROCm/HIP wheels remain unavailable
Metal wheels remain unavailable
combined accelerator wheels remain unavailable
Windows wheels remain unavailable
PyPI or another package-index publication is not claimed
```

This ledger records the checked readiness path and publish-time artifact
boundary for the GitHub prerelease. The checksum manifest is published outside
the source distribution payload and remains the publish-time source of truth for
artifact hashes.
