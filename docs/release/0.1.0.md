# FastPauli 0.1.0 Release Evidence

Status: prepared for PyPI package-index release `v0.1.0`; not yet published.

## Scope

`0.1.0` is the first final CPU wheelhouse release lane for FastPauli. It
promotes the checked `0.1.0rc2` runtime surface and the hosted wheelhouse dry
run into exact-tag CPU wheelhouse evidence without expanding
accelerator, Windows, macOS x86_64, or broad hardware support claims.

The release artifact support boundary is:

```text
CPU source distribution
CPU wheels for manylinux x86_64 and macOS arm64
CPU wheels for CPython 3.10, 3.11, and 3.12
CUDA source builds remain available when explicitly enabled from source
ROCm/HIP source builds remain available when explicitly enabled from source
Apple Metal source builds remain available when explicitly enabled from source
CUDA wheels remain unavailable
ROCm/HIP wheels remain unavailable
Metal wheels remain unavailable
combined accelerator wheels remain unavailable
Windows wheels remain unavailable
macOS x86_64 wheels remain unavailable
PyPI publication is not claimed
```

This ledger remains in pre-publication status for the final PyPI release. The
corrected `v0.1.0` tag-ref workflow produced the complete CPU wheelhouse,
uploaded it to TestPyPI, and passed a clean TestPyPI install smoke. The PyPI
workflow then rebuilt and revalidated the same package shape but failed at the
PyPI trusted-publishing exchange because PyPI has no matching publisher for the
observed `pypi` environment claims. PyPI publication must not be claimed until
the PyPI trusted publisher is configured for those claims and the tag-ref
publish job succeeds.

## Release-Tag Strategy

The `v0.1.0` tag has been corrected to the package-index-valid release
metadata revision after verifying that neither PyPI nor TestPyPI had accepted a
`fastpauli` `0.1.0` artifact and that GitHub did not have a `v0.1.0` release
object. Because TestPyPI has now accepted `0.1.0`, do not retag `v0.1.0` again
without moving to a new version such as `0.1.0.post1` or `0.1.1`.

The remaining PyPI finalization path is:

```text
configure PyPI trusted publisher for repository sghowell/FastPauli
configure PyPI trusted publisher for workflow release-wheelhouse.yml
configure PyPI trusted publisher for environment pypi
rerun Release Wheelhouse from ref v0.1.0 with publish-target=pypi
verify PyPI install smoke from a clean virtual environment
create the GitHub release object only after PyPI succeeds
```
