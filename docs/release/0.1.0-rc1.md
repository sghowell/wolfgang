# FastPauli 0.1.0-rc1 Release Evidence

Status: published as GitHub prerelease `v0.1.0rc1` with source distribution,
macOS arm64 CPU wheel, and external checksum manifest artifacts.

## Scope

`0.1.0-rc1` is the first CPU-focused release-candidate lane for FastPauli. The
release artifact support boundary is:

```text
CPU source distribution
CPU wheels for platforms that pass build, install, import, and scalar fallback evidence
CUDA source builds remain available when explicitly enabled from source
ROCm/HIP source builds remain available when explicitly enabled from source
Apple Metal source builds remain available when explicitly enabled from source
CUDA wheels remain unavailable
ROCm/HIP wheels remain unavailable
Metal wheels remain unavailable
combined accelerator wheels remain unavailable
```

This ledger records both the checked readiness path and the publish-time
artifact evidence for the GitHub prerelease. The checksum manifest is published
outside the source distribution payload.

## Supported Versions And Platforms

`pyproject.toml` declares:

```text
requires-python: >=3.10
classifiers: Python 3.10, Python 3.11, Python 3.12
```

Evidence in this ledger covers:

```text
local macOS arm64 CPU wheel on Python 3.12
CI validation on Linux x86_64 with Python 3.10 and Python 3.12
CI validation on macOS arm64 with Python 3.12
CI CPU wheel smoke on Linux x86_64 with Python 3.12
CI CPU wheel smoke on macOS arm64 with Python 3.12
```

Windows wheels, macOS x86_64 wheels, Python 3.11 wheels, and accelerator wheels
are not claimed by this ledger.

## Support Boundaries

```text
CPU target status: scalar fallback required in every CPU wheel
CUDA status: source-build lane only, no wheel claim
ROCm/HIP status: source-build lane only, no wheel claim
Apple Metal status: source-build lane only, no wheel claim
Combined accelerator status: unavailable by current target-specific build policy
Native CPU tuning: disabled for release wheels
```

The local artifact smoke verified:

```text

cuda_enabled is False
hip_enabled is False
metal_enabled is False
native_enabled is False
compiled_backends == ["cpu"]
"scalar" in compiled_cpu_backends
```
