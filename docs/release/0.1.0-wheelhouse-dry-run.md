# FastPauli 0.1.0 Wheelhouse Dry-Run Evidence

Status: manual release-wheelhouse dry run passed with `publish-target=none`.
No TestPyPI or PyPI publication was attempted or claimed.

## Scope

This ledger records the first hosted dry run of the final CPU wheelhouse
workflow. The run used the current package metadata version, `0.1.0rc2`,
because the final `0.1.0` version bump and release tag do not exist yet.

The dry run validates the release mechanics for:

```text
source distribution build
manylinux x86_64 CPU wheels for CPython 3.10, 3.11, and 3.12
macOS arm64 CPU wheels for CPython 3.10, 3.11, and 3.12
installed-wheel smoke in cibuildwheel
merged-artifact metadata checks
sorted SHA256 checksum manifest generation
exact one-sdist-plus-six-wheel CPU wheelhouse shape
checksum-free publish upload directory preparation
trusted-publishing jobs remaining skipped when publish-target=none
```

The dry run does not validate:

```text

final v0.1.0 tag-ref execution
TestPyPI trusted publishing
PyPI trusted publishing

ROCm/HIP wheels
```

## Hosted Job Results

```text

CPU wheels / macos-arm64: passed
Collect wheelhouse: passed
Validate publish ref: skipped
Publish to TestPyPI: skipped
Publish to PyPI: skipped
```

The first dry-run attempt exposed a collect-job metadata-tooling gap:
`twine check dist/*` ran with stale system/user-site metadata support and
rejected the modern `license-expression` field. Commit
`b41ba69e9beb08ff76ce53b4094d984c736a03a7` fixes that by installing Python
3.12 through `actions/setup-python@v5` in the `collect-wheelhouse` job before
merged artifact metadata checks run. The release-wheelhouse checker now
structurally guards that ordering.

## Local Artifact Validation

The downloaded hosted artifact was validated with:

```bash

.venv/bin/python scripts/write_release_checksums.py --dist-dir /tmp/fastpauli-release-wheelhouse-25449978931 --require-cpu-wheelhouse
.venv/bin/python -m twine check /tmp/fastpauli-release-wheelhouse-25449978931/*.whl /tmp/fastpauli-release-wheelhouse-25449978931/*.tar.gz
.venv/bin/python scripts/prepare_publish_dist.py --dist-dir /tmp/fastpauli-release-wheelhouse-25449978931 --publish-dir /tmp/fastpauli-publish-dist-25449978931
```
